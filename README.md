# BBT 设计参考 · 布局样板房

面向 Agent 与开发者的界面布局参考库：零圆角、粗边框、硬阴影的工业风格设计系统，提供可直接复用的页面布局样板。

## 启动

```bash
npm install
npm run dev      # Vite dev server → http://localhost:5174
npm run build    # 生产构建 → dist/
```

## GitLab Pages 在线预览

CI（`.gitlab-ci.yml`）自动把 `npm run build` 的产物发布到 GitLab Pages，合并到 `main` 后即可在线查看设计效果：

```
${CI_PAGES_URL}          # 具体地址见流水线 pages 作业 / 项目 Settings → Pages
```

- 构建走 `npm ci + types:check + build`，Pages 作业消费该 artifact（不重复构建）
- 路由用 HashRouter + `vite base: './'`，站点部署在任意子路径下资源均可加载
- 本地预览生产构建：`npm run preview`

## 布局样板房（`/#/showroom`）

52 个布局样板（多数可交互），每个场景是一个独立组件，源码位于 `src/showroom/scenes/`，可直接复制作为页面起点。

| 分类 | 场景 |
|------|------|
| 导航与结构 | 可收起侧边栏、分屏拖拽、粘性页头/页脚、全高布局、顶部导航+下拉菜单、面包屑、分页器、移动端底部标签栏 |
| 滚动与视差 | 鼠标驱动滚动、滚动触发动画、长文+悬浮目录、水平滚动、Scroll-Snap、无限滚动、轮播、虚拟滚动长列表 |
| 表单与流程 | 多步骤表单、复杂表单分组、Onboarding 向导、登录/注册分屏、筛选侧栏+结果网格、标签输入 |
| 数据与仪表 | 仪表板、响应式表格、瀑布流、看板、可排序表格、树形视图、文件管理器、实时监控大屏 |
| 内容展示 | 详情页+FAB、文章页、Hero 首屏、图文混排、灯箱画廊、定价页、对比滑块 |
| 状态与浮层 | 空状态、骨架屏、Modal 层级、命令面板、通知中心、右键菜单、工具提示 |
| 交互密集型 | 标签页、动态流、聊天、日历、评论线程、头像堆叠+成员管理、垂直时间轴 |

## 布局核心规则

- 全部尺寸基于 4px 网格
- 零圆角；阴影为硬阴影（无模糊，固定偏移）
- 布局优先用 Flex/Grid 表达层级，避免绝对定位堆叠
- 多数场景带 base/md/lg 响应式断点处理（纯静态样板场景除外）

## 技术栈

React 18 + TypeScript + Vite + Chakra UI + Framer Motion + React Router 6
